発表実績

今回の課題研究は校内で行われる課題研究発表会で注目されるようなものを作成したいと考えています。

1. 研究概要 (Abstract)

少し前から教室内の空気環境や生徒の学習態勢が学習効率に影響を与えることが指摘されています。自分の班の課題研究ではでは、Raspberry Pi 5とカメラモジュール、AI画像認識技術を組み合わて、授業中の生徒の姿勢や「居眠り」をリアルタイムで感知するシステムを構築しました！

このシステムにより、教員が遠隔から教室内の状況を把握して、適切な指導や環境改善のアプローチを取ることが可能になります。また、取得したデータはWebアプリケーション上で可視化されます。そこで直感的なインターフェースで確認できる仕組みを開発しています！！

2. 背景・目的・これまでの過程

課題：生徒の姿勢改善と成績低下の防止

授業中に居眠りをしてしまい、結果的に成績が足りず進級が危ない生徒が存在します。また居眠りは印象悪いです。こうした状況を未然に防ぐため、先生が遠隔で「寝ている生徒」や「姿勢が崩れている生徒」を把握できるようにすることが本研究の出発点です。

本研究の目的

  • 1 Raspberry Pi 5とカメラを用いて、教室内向けのポータブルな「姿勢・居眠り感知センサー」を制作する。
  • 2 AI画像認識を活用し、リアルタイムに生徒の姿勢データを取得・判定する仕組みを構築する。
  • 3 教員が遠隔で状況を把握できる使いやすいWebアプリケーションを開発する。

今までの過程・進捗状況

5月28日

課題研究の内容として、誰がどのようなものを担当するかなどの役割分担（プログラミング、Webアプリ作成など）を決定しました。また、開発に向けて何が必要か、物品の整理や洗い出しを行いました。

2日目：ラズパイセティング

6月4日

サイト班は文を全て手打ちにすることと、プログラミング班はラズベリーパイのパイソンのコードを入力しました。

AI組み込み・プロトタイプ作成

現在進行中

判定用AI画像認識ライブラリの検証を進めています。骨格や目元の特徴点を正確に捉えるモデルの選定と最適化を行って作成しています。

3. 研究手法と構成システム

本システムは「データ計測部（ハードウェア）」「クラウド蓄積部（データベース）」「通知・可視化部（Web/アプリケーション）」の3つのブロックで設計・開発を行いました。

1. センシング

Raspberry Pi 5と専用カメラモジュールを使用し、教室内を定期的に撮影・画像処理を行います。

2. AI姿勢判定

取得した画像から人物の骨格や顔の傾きを検知し、「居眠り状態」であるかAIモデルが判定します。

3. Webアプリ可視化

判定結果はWebアプリケーションに送信され、先生が遠隔からリアルタイムで確認できるダッシュボードとして表示されるようにしています。

4. 実験結果・考察

実験結果に対する考察

うつ伏せや正常姿勢に対しては高い検知率を誇る一方で、「首の緩やかな傾き」や「浅い居眠り」の際に検知率がやや低下（84%）する傾向が見られました。これは、カメラの設置角度によって顔の一部が死角に隠れてしまうことが主な要因と考えられます。

Raspberry Pi 5の処理能力（FPS）は極めて安定しており、リアルタイムの画像判定処理を遅延なく行えることが実証されました。今後は、逆光時や部屋の明暗による精度の変化をカバーする補正アルゴリズムの実装が必要です。

5. 結論と展望

本研究の結論

Raspberry Pi 5とAI画像認識を統合することで、教室内でのポータブルな居眠り感知システムの基盤モデルを完成させることができました。Webアプリケーション経由で遠隔から教員がリアルタイムにデータを取得・監視できる仕組みが実現し、学習環境改善へのアプローチとして十分な実用性を秘めていることが確認されました。

今後の課題とアプローチ

ハード面：複数人の同時認識

1名～数名を対象とした検知です一括でスキャンできるように、カメラの広角化とラズパイの処理効率化を進めます。

運用面：プライバシーへの配慮

教室内の映像をそのまま保存するのではなく、骨格ベクトル（点と線）の情報のみを数値化してデータ送信する、セキュリティ性の高い仕組みへとアップデートします。
